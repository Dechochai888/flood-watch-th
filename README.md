# น้ำท่วมไหน

WebApp แจ้งและติดตามจุดน้ำท่วมจากคนในพื้นที่ ผู้ใช้สามารถปักหมุดบนแผนที่ ใช้ตำแหน่งปัจจุบัน ระบุความรุนแรงและระดับน้ำ พร้อมแนบรูปภาพเพื่อช่วยให้คนใกล้เคียงวางแผนเดินทางได้ปลอดภัยขึ้น

## ความสามารถหลัก

- แผนที่ OpenStreetMap แบบโต้ตอบ
- ใช้ตำแหน่งปัจจุบันหรือแตะแผนที่เพื่อปักหมุด
- แบ่งระดับสถานการณ์เป็น เฝ้าระวัง / ควรหลีกเลี่ยง / อันตราย
- ระบุระดับน้ำ รายละเอียด และชื่อจุดสังเกต
- อัปโหลดภาพจากกล้องหรือคลังภาพ
- กรองรายงานตามระดับความรุนแรง
- รองรับทั้งมือถือและคอมพิวเตอร์
- บันทึกรายงานด้วย Cloudflare D1 และเก็บภาพด้วย R2

## เริ่มต้นใช้งาน

ต้องใช้ Node.js 22 ขึ้นไป

```bash
npm ci
npm run dev
```

เปิด `http://127.0.0.1:5173`

## ตรวจเวอร์ชันพร้อมใช้งานจริง

```bash
npm run build
npm start -- --port 5173
```

## ฐานข้อมูลภายในเครื่อง

หลังแก้ `db/schema.ts` ให้สร้าง migration ใหม่ด้วย:

```bash
npm run db:generate
```

สร้างโปรเจกต์ก่อน แล้วนำ migration ที่ยังไม่เคยใช้ไปลงฐานข้อมูลภายในเครื่อง:

```bash
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_nice_guardian.sql
```
